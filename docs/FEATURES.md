# 🎯 FocusTask v0.1.0 — 功能文档

> 轻量、高效、完全离线可用的个人桌面待办管理工具  
> Tauri v2 + React 18 + TypeScript + SQLite

---

## 一、核心功能

### 1. 任务管理

| 功能 | 说明 |
|------|------|
| 创建/编辑/删除 | 快速添加任务，支持编辑面板修改所有字段 |
| 优先级 | P0 紧急 / P1 高 / P2 中 / P3 低，颜色标识 |
| 截止日期 | 设置到期时间，逾期红色标注 |
| 提醒通知 | 到期前系统推送通知，支持延时和完成操作 |
| 重复任务 | 每日/每周/每月/工作日/自定义间隔 |
| 子任务 | 层级展开，支持批量管理 |
| 标签系统 | 多标签，颜色区分，一键筛选 |

### 2. 清单管理

| 功能 | 说明 |
|------|------|
| 自定义清单 | 创建、命名、设置图标和颜色 |
| 智能列表 | 今天、本周、逾期、重要、全部 — 自动筛选 |
| 清单归档 | 归档不删除，保留完整数据 |

### 3. 视图模式

| 视图 | 快捷键 | 说明 |
|------|--------|------|
| ⬆ 列表视图 | 点击切换 | 经典列表，拖拽排序，搜索筛选 |
| ⬆ 看板视图 | 点击切换 | 待办/进行中/已完成三列，拖拽卡片切换状态 |
| ⬆ 日历视图 | 点击切换 | 月/周/日模式，任务按截止日期显示 |

### 4. 快捷操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + N` | 全局唤醒快速添加窗口 |
| `Ctrl + K` | 命令面板 — 搜索任务、切换视图、快速创建 |
| `Ctrl + ,` | 设置面板 |
| 拖拽任务 | 列表排序 / 看板切换状态 |

### 5. 搜索与筛选

- **全文搜索**：SQLite FTS5，搜索任务标题和描述
- **标签过滤**：点击标签即可筛选，再次点击取消
- **智能列表**：今天/本周/逾期/重要，一键切换

### 6. 系统集成

| 功能 | 说明 |
|------|------|
| 系统托盘 | 最小化到托盘，左键恢复，右键菜单控制 |
| 关闭到托盘 | 点击关闭按钮 = 最小化，不退出 |
| 开机自启 | 设置面板可配置 |

### 7. 主题与个性化

| 选项 | 说明 |
|------|------|
| 浅色模式 | 经典白底 |
| 深色模式 | 暗色护眼 |
| 跟随系统 | 自动跟随 Windows/macOS 主题切换 |

### 8. 数据导入导出

| 格式 | 用途 |
|------|------|
| JSON | 完整备份，包含所有任务和清单，可跨设备迁移 |
| CSV | 表格导出，BOM 编码，Excel/WPS 直接打开 |

### 9. 数据安全

- ✅ 所有数据默认存储于本地设备
- ✅ SQLite 数据库，支持崩溃恢复
- ✅ 不收集任何用户使用数据
- ✅ 不依赖任何后台服务
- ✅ 完全离线可用

## 二、安装部署

### Windows

运行 `FocusTask_0.1.0_x64-setup.exe` 安装包，一路下一步即可。

### 开发构建

```bash
npm install
npm run tauri dev     # 开发模式
npm run tauri build   # 生产构建
```

## 三、技术架构

```
┌─────────────────────────────────────┐
│  UI 层 (React 18 + Tailwind CSS)    │
│  列表 · 看板 · 日历 · 命令面板      │
└──────────────┬──────────────────────┘
               │ Tauri Invoke
┌──────────────▼──────────────────────┐
│  Rust 后端                          │
│  SQLite · FTS5 · 提醒 · 托盘 · 快捷键│
└─────────────────────────────────────┘
```

| 层 | 技术 |
|----|------|
| 桌面框架 | Tauri v2 (Rust + WebView2) |
| 前端 | React 18 + TypeScript + Vite |
| UI | Tailwind CSS |
| 状态管理 | Zustand |
| 数据库 | SQLite (rusqlite) + FTS5 全文搜索 |
| 安装包 | NSIS (.exe) |
